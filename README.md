# Legalize-CN

> 🇨🇳 中国法律 Git 时间旅行仓库 — Law as Code

将中国法律文本转换为 Git 版本控制，实现法律演变的"时间旅行"功能。每个修正案对应一个 commit，用 `git diff` 精确对比法律变迁，用 `git checkout` 回溯任意历史版本。

灵感来自 [Legalize-es](https://github.com/abogados-legalize/legalize-es)（西班牙法律 Git 仓库）。

## 🎯 项目愿景

**Law as Code** —— 让法律像代码一样被版本控制、被追踪、被比较。

通过 Git 的版本控制能力，我们可以：

- 📜 **追溯历史**：查看每部法律从诞生到现在的完整演变历程
- 🔍 **精确比较**：使用 `git diff` 比较任意两个版本之间的具体差异
- ⏰ **时间旅行**：使用 `git checkout` "穿越"到任意历史时间点查看法律状态
- 🤖 **机器可读**：标准化的 Markdown + YAML frontmatter 格式，便于程序化处理

### 时间旅行示例

```bash
# "穿越"到2004年查看当时的宪法
git log --format="%H %ad" --date=short "constitution/中华人民共和国宪法.md"
# 找到2004-03-14对应的commit hash
git checkout <hash>

# 查看当时的宪法内容
cat "constitution/中华人民共和国宪法.md"

# 返回最新版本
git checkout history-rebuild
```

### 比较法律版本差异

```bash
# 比较宪法2004修正和2018修正之间的具体条文变化
git diff <2004-commit> <2018-commit> "constitution/中华人民共和国宪法.md"

# 比较刑法修正案(八)和修正案(九)之间的差异
git diff <2011-commit> <2015-commit> "laws/中华人民共和国刑法.md"
```

### 文件格式

每个法律文件采用以下格式：

```markdown
---
title: 中华人民共和国刑法
publish_date: 1997-03-14
effective_date: 1997-10-01
authority: 全国人民代表大会
doc_number: 主席令第八十三号
level: 法律
status: 现行有效
---

# 中华人民共和国刑法

## 第一编　总则

#### 第一条　为了惩罚犯罪，保护人民...
```

Markdown层级映射标准：

| 法律结构 | Markdown层级 | 说明 |
|----------|-------------|------|
| 编 (Part) | `# H1` | 最高结构单元 |
| 章 (Chapter) | `## H2` | 章标题 |
| 节 (Section) | `### H3` | 节标题 |
| 条 (Article) | `#### H4` | 统一使用H4 |
| 款 (Paragraph) | 自然段落 | 无标记 |
| 项 (Item) | 有序/无序列表 | (一)、(二)... |

修正案文件额外包含 `amendment_number` 和 `applies_to` 字段：

```markdown
---
title: 中华人民共和国刑法修正案（八）
amendment_number: 8
applies_to: 中华人民共和国刑法
...
---
```

## 🔧 技术架构

本项目由自动化流水线 [`legalize-builder`](./legalize-builder/) 生成，包含以下核心模块：

| 模块 | 功能 |
|------|------|
| `scrapers/` | 数据抓取（国家法律法规数据库、中国政府网、Wikisource） |
| `parsers/` | 文本解析（归一化、结构解析、元数据提取、Markdown生成） |
| `git_engine/` | Git 时间旅行引擎（伪造提交时间、历史重建、差异分析） |
| `scripts/` | 专用脚本（格式统一、修正案历史重建、批量提交等） |
| `main_pipeline.py` | 主流水线编排 |

### 核心特性

- **文本归一化**：处理全角空格、Unicode特殊字符、BOM等
- **结构解析**：识别 编→章→节→条→款→项→目 层级结构
- **时间伪造**：`GIT_AUTHOR_DATE` 设置为法律发布日期
- **修正案历史重建**：从Wikisource获取中间版本，重建完整Git时间线
- **缓存机制**：避免重复网络请求，防止被封禁
