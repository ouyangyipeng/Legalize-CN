# 果洛藏族自治州第十四届人民代表大会关于废止《果洛藏族自治州畜禽防疫条例》的决定

#### 第一条 果洛藏族自治州第十四届人民代表大会

关于废止《果洛藏族自治州畜禽防疫条例》的决定

（2018年1月16日果洛藏族自治州第十四届

人民代表大会第三次会议审议通过）

本决定自批准之日起施行。
